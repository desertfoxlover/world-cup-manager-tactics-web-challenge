3. **배포 URL이 심사 기간 내내 동작**, 키/로그인 없이 체험 가능  
4. 기획서 · 서비스 · 시연 영상이 **하나의 스토리**로 연결됨  
5. GitHub README에 실행 방법·기술 스택이 명확함
