## 후보 A — **What If Board** (추천 1순위)

**한 줄:** 실제 월드컵 경기(또는 대표팀 스쿼드)를 불러와,  
"내가 감독이었다면" 라인업·포메이션을 다시 짜고 **차이·리스크**를 바로 보여준다.

### 핵심 루프

1. 국가대표 / 매치 선택  
2. 실제(또는 기본) 라인업 로드  
3. 드래그로 선수 재배치 · 포메이션 변경 · 교체  
4. 보드 옆에서 **스탯 밸런스 / 포지션 적합성 / 상대 대비** 피드백  
5. "내 전술 카드" 결과 화면 (공유용 이미지 선택)

### 왜 강한가

- 공식 예시와 정확히 맞음  
- AI 없이도 완성도 있게 가능 (규칙 기반 점수)  
- 시연 영상이 만들기 쉬움

### 리스크

- 2026 확정 스쿼드가 아직 불완전할 수 있음 → **2022 + 2026 예선/확정 팀 혼합** 또는 **샘플 확정 스쿼드 JSON**으로 대응

---

## 후보 B — **Live Bench Boss**

**한 줄:** 가상(또는 과거) 경기 타임라인 위에서 스탯이 흐르고,  
감독이 **교체·전술 스위치**를 지시하면 이후 흐름/점수가 바뀐다.

### 왜 재밌는가

- "경기 중 감독" 몰입감이 큼

### 왜 위험한가

- 시뮬레이션/타임라인 구현 비용이 큼 (2주에 과함)

→ **시간 남으면 A의 확장으로만** 검토.

---

## 후보 C — **AI Scout Desk**

**한 줄:** 상대팀 강·약점 분석 후 AI가 포메이션·키플레이어를 추천하고,  
유저가 보드에서 수정·확정한다.

### 주의

- 외부 LLM API 키 → **심사자 키 없음**이면 기능 평가 제한  
- 해결: Netlify AI Gateway / 서버 프록시 + 무료 티어, 또는 **오프라인 규칙 추천 + 선택적 AI**

→ A의 "추천 패널"로 축소하는 편이 안전.
