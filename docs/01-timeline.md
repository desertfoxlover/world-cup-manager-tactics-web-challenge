## 스코프 컷 우선순위 (시간 부족 시)

**남긴다**

1. 팀 선택 → 포메이션 → 드래그 배치  
2. 선수 카드(기본 스탯)  
3. 조작 결과 피드백 1종  
4. 배포 + 시연 영상

**자른다**

- 실시간 라이브 매치 API  
- 복잡한 물리 시뮬레이션  
- 계정/공유/소셜 로그인  
- 다국어 풀세트  
- AI 채팅 (시간 없으면 규칙 기반 추천으로 대체)
