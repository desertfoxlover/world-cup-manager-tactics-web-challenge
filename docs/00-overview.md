# 00. 대회 개요 · 규칙

## 한 줄 요약

> 축구를 보며 "내가 감독이라면…"을 **웹에서 직접 해보는** 동적 전술 서비스.

공식 문구 핵심: 바이브 코딩으로 설계·구현·배포하되,  
**드래그·클릭·배치·조작**으로 감독 경험이 느껴져야 한다.

---

## 공식 예시 (참고용)

| 예시 | 해석 |
| --- | --- |
| 드래그앤드롭 전술 보드 | 포메이션 + 선수 배치 UI가 핵심 |
| AI 맞춤 전술 추천 | 상대 데이터 분석 → 추천 (선택) |
| "내가 감독이었다면" 시뮬레이션 | 실제 경기 데이터 기반 시나리오 |
| 스탯 보며 교체·전술 변경 | 경기 중 의사결정 인터랙션 |

→ **필수는 "감독처럼 조작"** 이고, AI는 가점 요소.

- 배포 URL은 심사 기간 동안 외부 접근 가능

## 심사 포인트 (페이지에서 읽히는 신호)

1. **배포 URL 기준** 심사 (데모만으로는 부족)
2. 동적 인터랙션이 **실제로 동작**해야 평가 대상
3. 시연 영상에 시작 → 배치/전술 → 핵심 인터랙션 → 결과 흐름 포함
